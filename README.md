# VintageVerse – Full Stack MERN Blog Platform

VintageVerse is a full-stack MERN application with authentication, CRUD operations, and a responsive frontend.

## 🔗 Live Demo
Frontend: https://frontend-blog-project.onrender.com/  
Backend: https://backend-blog-project-5lv7.onrender.com/

---

## 🚀 Features
- JWT-based authentication and secure user management  
- Create, edit, and delete blog posts  
- Protected routes with author-only access  
- REST API integration with frontend  
- Responsive UI built with React  

---

## 🛠 Tech Stack
- Frontend: React (Vite), Tailwind CSS  
- Backend: Node.js, Express.js  
- Database: MongoDB  
- Authentication: JWT, Bcrypt.js  

---

## ⚙️ Setup
1. Clone the repository  
2. Install dependencies (client & server)  
3. Configure `.env` variables  
4. Run frontend and backend
